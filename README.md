# Тихая форма — стартовый сайт магазина

Статический сайт без сборки и фреймворков. Подходит для публикации через GitHub Pages.

## Как посмотреть

Откройте `index.html` в браузере. Для публикации держите `index.html`, `styles.css`, `script.js` и пять фотографий в корне репозитория и включите GitHub Pages в настройках репозитория: **Settings → Pages → Deploy from a branch → main → /(root)**.

## Что заменить перед публикацией

1. «Тихая форма» — рабочее название. Найдите его в `index.html` и замените, когда выберете название бренда.
2. Заказ — через Instagram: ссылка на профиль `kriss.tiana` добавлена в шапку и контактный блок.
3. Названия товаров пока рабочие, цены выставлены по вашим вводным: свечи — 499 ₽, вазы-копилки — 399 ₽.
4. Фотографии `candle-01.jpg`–`candle-05.jpg` находятся в корне репозитория. Замените изображения своими, сохранив имена файлов, либо поправьте пути в `index.html`.
5. В условиях сейчас указано: доставка СДЭК по России до 7 дней.

При первом открытии прокрутите экран, чтобы раскрыть жалюзи и перейти к сайту. Сайт адаптируется под телефон и компьютер. Внешние шрифты загружаются из Google Fonts; при недоступности сервиса останутся системные шрифты.
